# 계절근로자 급여검증 — RAG 파트

R00~R11 규칙 엔진이 내린 판정에 **법령 근거를 붙여 설명하는** 레이어

```
[OCR → 사용자 확인 → R00~R11 룰 엔진 판정]   ← 팀 공통 (다른 브랜치)
                  ↓
        r04_result: MISMATCH
        cmp_housing_deduction_gap: 80,000
                  ↓
┌───────────────────────────────────────────────┐
│  이 브랜치                                      │
│   ① 법령 코퍼스     조·항 단위 수집·저장          │
│   ② Retrieval      규칙 → 근거 조항 확정         │
│   ③ 리포트          불일치·근거·대응 방법 생성     │
└───────────────────────────────────────────────┘
                  ↓
   "표준 계절근로계약서 제10항 「숙식 제공」 기준
    계약 120,000원 vs 명세서 공제 200,000원.
    값이 다르다는 사실 자체가 법 위반은 아닙니다."
```

근거 검색·조문 인용·해석 수위·대응 방안이 모두 결정적이라, API 키 없이 같은 입력에 항상 같은 결과 나옴

## 설계

### 판정 성격이 설명 수위를 결정한다

모든 Rule이 법 위반을 판단하는 것이 아님. 근거 조항이 붙어 있다는 이유만으로
"법 위반"이라고 설명하면 안 되는 규칙이 절반이 넘음

| 성격 | 뜻 | 해당 규칙 |
|---|---|---|
| **법적기준** | 법령이 직접 규율하는 의무. 위반 가능성을 말할 수 있다 | R08, R09, R11 |
| **문서정합성** | 문서 간 값이 다른지 확인. 차이 자체는 위반이 아니다 | R01~R04, R10 |
| **산술검산** | 명세서 내부 계산 확인. 법령이 산식을 정하지 않는다 | R05, R06, R07 |
| **시스템규칙** | 법적 근거 없이 자료를 연결하는 절차 | R00 |

규칙마다 **금지표현**을 함께 정의. R05~R07에는 `"임금 체불"`,
`"합계가 맞지 않으므로 법 위반"`이 금지어.

### 조건부 근거

R03의 제56조(가산임금)는 연장·야간·휴일 근로가 실제 쟁점일 때만 인용.
R02·R03·R10의 제63조(적용의 제외)는 농림·축산·수산업일 때만 적용.
각 근거에 `적용조건`이 붙어 있어, 조건 확인 전에는 인용되지 않음.

```
[조건부] 근로기준법 제63조(적용의 제외) 제1항
   "이 장과 제5장에서 정한 근로시간, 휴게와 휴일에 관한 규정은 … 적용하지 아니한다"
   → 사업장 업종이 농림·축산·양잠·수산 사업에 해당하는 경우에만 적용.
```

### Retrieval 2경로

**1차 — 매핑 테이블.** 규칙이 R00~R11로 고정된 폐쇄 도메인이라, 검색에 맡기지 않고
근거를 직접 지정. 조·항뿐 아니라 **호 단위까지** 내려감.
근로기준법 시행령 제27조의2 제1항은 호별로 대응 규칙이 갈림.

| 호 | 내용 | 대응 규칙 |
|---|---|---|
| 1호 | 근로자 특정 정보 | R00 |
| 2호 | 임금지급일 | R09 |
| 3호 | 임금 총액 | R01, R05, R07 |
| 4호 | 구성항목별 금액 | R01, R03, R05 |
| 5호 | 계산방법(연장·야간·휴일 시간 수 포함) | R01, R02 |
| 6호 | 공제 항목별 금액·총액 | R04, R06, R07 |

**2차 — BM25 키워드 검색.** 매핑에 없는 상황이나 보조 근거용.
형태소 분석기 없이 어절 + 문자 바이그램(가중치 0.3)으로 색인.
검증 세트 기준 정답 1위 6/7, 상위3 포함 7/7.

```python
from law.retrieval import Corpus
corpus = Corpus.load()
corpus.search("근로자가 퇴직한 경우 14일 이내 금품 청산")
# → 근로기준법 제36조(금품 청산)
```

임베딩을 쓰지 않는 이유: 폐쇄 도메인에서 매핑이 더 정확하고 비용이 0이며 근거를
설명할 수 있음. 필요해지면 `search()` 시그니처를 유지한 채 내부만 교체하면 됨.

### 표준 계절근로계약서는 번호가 아니라 의미로 참조

공식 서식(별지 제3호)과 합성데이터 서식(별지 제1호)의 항 구성이 다릅니다.

| 공식 (별지 제3호서식) | 합성데이터 (별지 제1호서식) |
|---|---|
| 제4항 근로시간 / 제5항 휴게시간 / 제6항 휴일 | 4. 근로시간·휴게·휴일 (통합) |
| 제7항 임금 / 제8항 지급일 / 제9항 지급방법 | 5. 임금 (지급일·방법 포함) |
| 제10항 숙식 제공 | 6. 숙식 제공 |

번호로 매핑하면 서식이 개정될 때마다 근거가 어긋납니다. 의미 키(`근로시간`, `숙식제공`)로
참조하고 번호는 인용 문자열을 만들 때만 씁니다. 리포트는 양쪽을 병기합니다.

### 필드 한글명은 피처정의서에서 읽음

`cmp_actual_hours_gap` → `실근로시간 차이 (프로그램 계산)`

이름을 코드에 따로 쓰면 팀 공통 원본과 반드시 어긋나므로,
`R00-R11_통합_표준피처정의서_v4.xlsx`의 `01_전체_피처사전` 시트(194개 필드)를 직접 읽습니다.

```

├── features.py    피처정의서 → 필드명 한글 변환
├── guidance.py    성격별 해석 문구 · 대응 방안 · 확인 질문

├── prompt.py      LLM 설명 프롬프트 · 출력 스키마   ※ 아래 참고
└── explain.py     Anthropic API 연결                ※ 아래 참고

법령데이터/
├── corpus.jsonl   조·항 1,486건
├── index.json     법령별 메타
└── raw/           API 원본 11개 (재파싱용)

예시케이스/         결함케이스 3건 (판정 성격 4종 전부 포함)
check_law_api.py    법령 API 연결 점검
```

### `prompt.py` · `explain.py` 는 다음 단계입니다

리포트는 **정보 구조**라 문장이 딱딱합니다. 근로자가 읽을 자연스러운 한국어로
다듬는 것은 Anthropic API의 몫이며, 그 프롬프트와 연결 코드가 이 두 파일입니다.

```bash
export ANTHROPIC_API_KEY="..."
python -m law.explain 예시케이스/CASE-2026-06-0004.json --dry-run   # 전송 내용만 확인
python -m law.explain 예시케이스/CASE-2026-06-0004.json             # 실제 호출
```

`--dry-run` 은 키 없이도 됩니다. 아직 실호출로 검수하지 않았습니다.

## 코퍼스 갱신

법령은 개정됩니다. 인용한 조문이 바뀌면 근거가 틀려지므로 주기적 재수집이 필요합니다.
각 레코드에 `시행일자`가 박혀 있어, 재수집 후 날짜가 바뀌면 매핑 재검증 신호가 됩니다.

권장 주기는 **분기 1회 재수집**, 최저임금 고시는 **연 1회(8월 고시 직후)** 입니다.
판정 실행과는 완전히 분리된 배치 작업입니다.

> 국가법령정보 API는 연속 호출이 잦으면 IP 단위로 연결을 리셋합니다(Errno 54).
> 한 번 걸리면 수십 분 풀리지 않아 `client.py`에 호출 간격 1.2초를 강제해 뒀습니다.

## 알려진 한계

**아직 수집하지 못한 근거 2종.** 매핑에는 등록돼 있어 인용은 나가지만 본문이 비어 있습니다.

- 2026·2027년 적용 최저임금 고시 — 행정규칙 API로 조회했을 때 `조문내용`이 빈 객체였습니다.
  고시 본문이 HWP 첨부파일에만 있을 가능성이 큽니다. 최저임금액은 `ref_minimum_hourly_wage`
  파라미터로 관리하고 고시는 출처 표기용으로만 쓰는 편이 낫습니다.
- 농어업고용인력 지원 특별법 시행규칙 별지 제3호서식 — 별표·서식 전용 API가 필요합니다.

**팀 검토가 필요한 매핑 3건** (`mapping.py`의 `검토필요` 필드)

- **R10** — 계약시간 대비 실근로시간 *부족*은 근로기준법상 위반이 아닙니다.
  제50조·제53조는 *초과*를 규율하는 조항이라, REVIEW 판정의 법적 성격 재정의가 필요합니다.
- **R04** — 숙식비 공제의 실질 근거가 고용노동부 예규일 수 있습니다.
  지방고용노동관서별 숙소비 가이드라인은 관할 지역이 다르므로, 사업장 소재지를 확인한
  경우에만 근거로 써야 합니다.
- **R02·R03** — 농림·축산·수산업의 제63조 적용 제외 여부를 확인하기 전에는
  법정 기준 위반으로 설명하지 않습니다.
